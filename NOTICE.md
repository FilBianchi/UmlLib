# Source attribution

UmlLib was extracted from https://github.com/FilBianchi/UmlTools.
The bundled `umltools/data/UML.xmi` is the UML 2.5.1 machine-readable metamodel
originally vendored as `doc/ptc-18-01-01.xmi`. UML and its specification are
published by the Object Management Group: https://www.omg.org/spec/UML/2.5.1/.
Native Python semantics and generated model declarations are maintained by this project.
